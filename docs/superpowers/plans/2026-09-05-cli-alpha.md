# ModelCaddie CLI Alpha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a tested, installable CLI alpha that demonstrates provider-neutral evaluation and produces honest, scoped usage guidance.

**Architecture:** Provider protocol and fixed-endpoint transport isolate vendor APIs. Validated task/config/report models feed objective grading and complete-coverage recommendation logic. CLI handles arguments and presentation only.

**Tech Stack:** Python >=3.11, standard-library runtime, setuptools, unittest, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-09-05-cli-alpha.md

## Global Constraints

- Python >=3.11; no runtime dependencies.
- No live paid model calls during development.
- Native settings remain provider-specific; no automatic model switching.
- Demo results never become production recommendations.
- Reference answers never enter provider prompts.
- Only fixed official HTTPS endpoints; no credential-bearing redirects.
- No generated-code execution, project uploads, or credentials in state.
- Recommendations require comparable complete coverage, at least 3 unique tasks, quality >=0.8, and explicit provisional status.
