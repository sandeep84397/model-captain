# Model Guide

Provider-neutral model calibration and usage recommendations for programming work.

**Status: alpha in development.** Measure exact model configurations against explicit tasks, then generate a scoped usage guide. No universal model rankings or claims that API results predict a native coding agent's performance.

The initial CLI will support an offline demo, OpenAI and Anthropic API adapters, objective task scoring, local reports, provisional recommendations, and instruction exports. See [the approved direction](docs/superpowers/specs/2026-09-05-cli-alpha.md) and [implementation plan](docs/superpowers/plans/2026-09-05-cli-alpha.md).
